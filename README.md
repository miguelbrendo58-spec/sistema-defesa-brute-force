# Sistema de Defesa Anti Brute-Force

Sistema de login em Python que bloqueia IPs após 3 tentativas falhas.
Projeto feito para aprender manipulação de arquivos e segurança.

## v1.0
- Bloqueio permanente em arquivo blacklist.txt
- Uso de dicionário para contar tentativas por IP
- Tratamento de erros com try/except
